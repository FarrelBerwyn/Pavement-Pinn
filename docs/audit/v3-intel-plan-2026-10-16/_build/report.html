1. Analisis hasil audit sebelumnya

  • Kekuatan nyata ada di fondasi perangkat lunak: alur multi-peran, RBAC server, pemisahan wewenang, audit trail, label provenance, 229 tes lulus. Ini memberi poin di M01 3.1/3.2 dan M02 2.4/4.2.

2.3 AGENTS.md — instruksi kerja agent coding

  • 9 aturan wajib: tanpa angka palsu; performa hanya dari measurements/; setiap keluaran model menyimpan asal-usul (MEASURED/COMPUTED/DEFAULT/ASSUMED); AI tidak mengubah status kasus; daftar frasa terlarang; deterministik; jangan melemahkan tes atau pindah stack; privasi foto; jangan commit kredensial/dataset.
  • Arsitektur target: React PWA → Express (sudah ada) → layanan Python FastAPI localhost:8100 dengan /v1/screen, /v1/assess, /v1/options, /v1/brief, /v1/measurements.
  • Fakta teknis terverifikasi: PyMastic butuh q dalam kPa bila E dalam MPa; iteration=20; tanda et = -Strain_R; nilai acuan εt ≈ 303 µε, εv ≈ 793 µε.
  • Fase 0–7 berurutan dengan kriteria selesai, konvensi PR kecil per ID temuan, trailer Assisted-by, modul ilmiah inti sebaiknya ditulis tim, dan Definition of Done demo.
